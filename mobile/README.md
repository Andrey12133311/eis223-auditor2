# ЕИС Аудитор — мобильные приложения

Приложения подключаются к действующему серверу:
https://web-production-1c2ea.up.railway.app/

Это мобильные клиенты существующей программы. Учётные записи, роли, документы,
самостоятельные, тематические и общие проверки обслуживаются тем же сервером.
Для работы требуется интернет. Автономной юридической проверки на телефоне нет.
Права администратора определяются сервером после обычного входа.

## Android

Подписанный APK для Android 8.0 и новее, без библиотек сторонней аналитики.
В приложении есть меню, переход в личный кабинет, внешние ссылки в браузере,
загрузка файлов через системный выбор и сохранение документов в выбранную папку.
Сеанс сайта хранится в WebView, в пределах срока действия серверной сессии.
Приложение не хранит пароль в исходном коде и не подменяет серверную авторизацию.

Установка: скачать APK → открыть файл → разрешить установку из данного источника
для браузера или приложения «Файлы» → «Установить».

Сборка: `python3 android/build.py --toolchain /path/to/toolchain --signing /private/signing-dir`.
Нужны официальные Android Build Tools 36.0.0, платформа Android API 36, Eclipse ECJ
3.37.0 и Java 17+. Подпись релизная; ключ не включается в публичный репозиторий.
Сохранённый ключ необходимо использовать при всех будущих обновлениях APK.

## iPhone и iPad

`EIS223-Auditor-iPhone.mobileconfig` — устанавливаемый профиль **веб-приложения**,
который добавляет на экран «Домой» значок действующего сайта с полноэкранным запуском.
Это не IPA. Профиль не устанавливает сертификаты, VPN, управление устройством или
ограничения. Веб-приложение требует интернет, как и Android-клиент.

Откройте профиль в Safari на iPhone. В настройках iPhone откройте «Профиль загружен»
и установите его. Если этого пункта нет: «Основные» → «VPN и управление устройством».
Профиль не подписан; iOS показывает его состояние при установке.
После установки запустите «ЕИС Аудитор» на экране «Домой» и войдите в свою учётную запись.
Если устройство не разрешает установку профилей, откройте сайт в Safari →
«Поделиться» → «На экран “Домой”».

В `ios/` находится отдельный нативный клиент SwiftUI/WKWebView для iOS 17+.
Для сборки нужны macOS, Xcode и XcodeGen (`brew install xcodegen`).
Запустите `cd ios && xcodegen generate`, откройте `EISAuditor.xcodeproj`,
в Signing & Capabilities выберите собственную Apple Developer Team.
Для установки на своё устройство выберите подключённый iPhone и Run.
Для подписанного IPA: Product → Archive → Distribute App с доступным способом распространения.

`ios/build-unsigned.sh` создаёт реальный ARM64 IPA без подписи Apple.
**Неподписанный IPA напрямую на iPhone не устанавливается.** Его нужно подписать
своими средствами распространения Apple. Файл `.mobileconfig` — отдельный способ
сразу добавить веб-версию на телефон.

## Проверка и ограничения

Сборка проверяет Java-код, политику адресов и подпись APK. В iOS-сборке CI
проверяет компиляцию для настоящего ARM64 устройства.
Проверки, требующие пароля пользователя, выполняются после его входа на телефоне.
Внешние сайты открываются отдельно; пароль и cookie ЕИС Аудитора им не передаются.
Пуш-уведомления и офлайн-работа не реализованы. Серверные email-уведомления
продолжают работать по существующим настройкам сервера.
