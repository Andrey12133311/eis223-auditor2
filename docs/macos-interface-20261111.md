# Обновление интерфейса: светлая компактная тема

## Что изменено

Единая нейтральная тема для входа и регистрации, общей панели, личного кабинета, реестра, кабинетов сотрудника и руководителя, карточки закупки и профиля. Системный шрифт, графитовый текст, синий акцент, светлые панели и тонкие разделители. Существующая навигация, формы, вкладки, роли, API, тексты и логика проверок сохранены.

Визуальный слой теперь применяется после компактных структурных стилей. Это сохраняет плотную компоновку и устраняет конфликт цветов. На сенсорных экранах основные элементы управления имеют высоту не менее 44 px. Таблица документов карточки прокручивается внутри себя, сохраняя читаемую ширину столбцов.

## Выпуск

Ветка release/macos-interface-20261111 основана на фактически работающем commit 82f78d29c184ecc3b828347261012cc4a7623891. Её diff содержит только визуальные builders, UI-проверки, локальный preview-инструмент и эту документацию. Dockerfile, команды запуска, переменные, диск, БД и правовые модули не менялись.

При начале работы Railway source указывал на fix/document-speed-legal-20261110 / c687b88a0f33a57b842bb533363f0121c3fc55ae (71 файл неопубликованных серверных изменений относительно live). При повторном чтении source.commitSha уже был b75f9a9f661eff5735d5d02b6257612b2c37727d, тогда как последним успешным deployment оставался 3edf82f4-5ab3-4041-a431-6597d81c3436 / 82f78d29. Обнаружено параллельное изменение источника; публикация этой ветки требует решения пользователя о согласовании с ним. Сам источник Railway в этой задаче не изменялся.

Безопасные варианты после такого решения: отдельный визуальный релиз поверх live с точной фиксацией commit либо перенос визуального коммита в согласованную актуальную серверную ветку. Перед действием перечитать Railway source, staged/pending state и последний deployment; не перезаписывать обнаруженную новую конфигурацию молча.

Инструмент 12ui был установлен и вызван для проработки, но hosted-этап потребовал отдельной авторизации. Отдельные варианты им не были получены. Реализован выбранный пользователем письменный подход; проверка соответствия выполнена локальным Chromium и независимым ревью, без заявления о завершённом hosted-процессе 12ui.
