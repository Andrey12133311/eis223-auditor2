# Проверка применимости нормы и идентичности юридического события

## Что изменено

1. Общая классификация явного способа закупки теперь различает конкурентную,
неконкурентную и неопределённую процедуру. «Неконкурентная», «закупка у единственного
поставщика», явное отрицание конкурентного способа не превращаются в конкурентную
процедуру из-за совпадения части слова. Название файла протокола не доказывает способ.
Противоречащие друг другу поля способа дают неопределённость.
2. Часть 11 статьи 4 больше не даёт подтверждённое нарушение без установленной
конкурентной процедуры. Неоднозначные даты остаются в «Требует проверки».
Публикация не заимствуется из соседнего решения или по одному совпадению имени файла;
для соединения истории с оригиналом требуется один однозначный день решения в том
же вложении ЕИС. Исправлена также ошибка необъявленной переменной срока подачи в
ветке проверки истории изменений.
3. При проверке разъяснений явно указанные номера запросов сопоставляются полностью.
Разные номера, номер только с одной стороны, неоднозначные версии и два адреса одного
вложения не образуют доказанную пару. Несколько однозначно пронумерованных запросов
проверяются отдельно. Повторные оригиналы не увеличивают счётчик. Разные номера
с одинаковыми датами сохраняются отдельно в базе, карточках и счётчиках.
4. Известные извещения до 2019 года не проверяются современным семейством конкурентных
правил без исторического пакета. Для изменений также проверяются известные даты событий.
Это защитный барьер, а не полноценный выбор редакции закона для всех дат.

## Источники и юридические ограничения

Сверен текст 223-ФЗ на официальном сайте МЧС:
https://mchs.gov.ru/uploads/document/2025-06-07/81c0ff552c6a12324d38e676f727a820.pdf
(редакция с изменениями по 08.08.2024, включая положения с 2025 года).
Часть 3 статьи 3.2: три рабочих дня для ответа и публикации разъяснений;
обязанность может отсутствовать при позднем запросе. Часть 11 статьи 4:
отдельный срок публикации изменений/разъяснений и условие продления срока после
изменения извещения/документации. Одно разъяснение само по себе не означает изменение.
Половина срока берётся из применимого положения о закупке для конкретного способа,
а не из произвольно выбранных 7 или 15 дней.

Переходные правила 505-ФЗ, статья 4:
https://www.garant.ru/products/ipo/prime/doc/71748836/
(текст первичного акта на коммерческом правовом ресурсе). Для закупок переходного
периода имеют значение дата извещения и публикация приведённого в соответствие
положения. Просто дата 01.07.2018 не решает применимость автоматически.

Исчерпывающая актуальность законодательства на 2026 год не подтверждена этим патчем.
Новые материально-правовые нормы и арифметика сроков не вводятся. Ограничения календаря,
исключения размещения, недоступность ЕИС и исторические редакции требуют отдельной
доказательственной проверки. Количество результатов не является мерой точности.

## Сохранённые результаты и границы

Правила действуют на новые анализы и явно запущенные повторные проверки сохранённых
оригиналов. Массовая очередь перепроверки не запускается: RULE_REVISION не изменена.
Прежние находки и решения руководителей не удаляются и не переквалифицируются.
Для очистки ранее ошибочных результатов необходима отдельная сверка с сохранением
истории согласования. Патч не заявляет, что старые карточки автоматически исправлены.

Дедупликация изменений документации по одинаковым датам остаётся консервативной:
разные URL сами по себе не доказывают разные акты. Отдельная идентификация номеров
изменений для увеличения полноты в этот патч не входит. Старый ненумерованный режим
единственной пары разъяснений сохранён; отсутствующие/непрочитанные оригиналы не
дают доказательства отсутствия ответа. Универсальная идентификация лотов и всех
событий во всех юридических слоях не заявляется.

Внешний загрузчик VPS, XML, почта, роли, реальные назначения сотрудников и реальные
решения по нарушениям не изменяются.
