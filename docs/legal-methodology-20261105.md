# Обоснование результатов проверки

Методология применяется в общей, самостоятельной и тематической проверке до сохранения новых результатов. Лист внеплановой проверки использует те же решения по 19 критериям. Пустые данные и отсутствие найденного нарушения сами по себе не подтверждают соответствие.

## Пределы доказательства

- Подтверждённое получение оригинала из ЕИС доказывает происхождение файла. Дополнительно проверяется, является ли фрагмент условием закупки, совершённым действием, образцом, инструкцией или цитатой.
- Образцы протоколов, учебные примеры и цитируемые нормы не доказывают фактическое отклонение заявки, отмену закупки или публикацию разъяснения. Выявленный кандидат остаётся на дополнительной проверке с исходной цитатой.
- Явно отменённые или заменённые редакции не используются как доказательство действующего условия. Актуальность не выводится только из даты в имени файла. Исторический материал сохраняется для проверки обстоятельств соответствующего периода.
- Проект договора может подтверждать предусмотренное закупкой условие, но не факт подписания договора, оплаты или решения комиссии.

## Проверка правовой квалификации

Для известных правил сопоставляются код, критерий листа, указанная норма и статусы результата. Явное противоречие между ними переводит кандидат в дополнительную проверку. Произвольная метка критерия не переопределяет известный код правила. Указание названия закона без нужной статьи и части недостаточно для подтверждения нормы.

Это проверка согласованности заключения, а не подтверждение любой редакции законодательства по одной строке ссылки. Применимость нормы, период, специальные исключения и достаточность первичных фактов по-прежнему проверяются соответствующим предметным правилом. Результаты правил за пределами 19 критериев не объявляются нарушениями этих критериев.

## Заявки субъектов МСП

Добавлена отдельная проверка условия документации по части 19.2 статьи 3.4 Закона № 223-ФЗ: непредставление документов для оценки квалификации само по себе не может быть основанием отклонения заявки в применимом электронном конкурсе или запросе предложений для субъектов МСП.

Подтверждённый результат требует доказанного режима закупки только среди МСП, подходящего способа и электронной формы, применимой даты и точного условия документации. Неподтверждённая область применения и противоречивые редакции оставляют вопрос на дополнительной проверке. Требование лицензии, оценка в ноль баллов и условие о непредставлении иных обязательных сведений не приравниваются к этому нарушению автоматически.

Такой вывод устанавливает дефект условия документации. Он не устанавливает, что конкретная заявка фактически отклонена, и сам по себе не является выводом об административном правонарушении.

Нормативный источник: [статья 3.4 Закона № 223-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_116964/a3b63487ad7d07ce045a07b0f1e7a9d9b064de95/). Для нового правила учитывается начало действия соответствующих положений с 01.04.2021; спорная дата не считается доказанной.

## Отчёт и обновление результатов

Причины дополнительной проверки, исходная цитата, документ и недостающие доказательства включаются в приложение к листу проверки. Столбец «Комментарии» остаётся пустым. Сохранённые решения руководителя и история проверки не удаляются. Изменение сигнатуры методологии делает прежний автоматический результат устаревшим; новый результат формируется после повторной проверки исходных документов.
