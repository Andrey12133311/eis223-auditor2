# V376: восстановление загрузчика после ошибок Railway

Изменения подготовлены поверх рабочей версии `f69a2cc` ветки
`thematic-audit-20261015`. Они не требуют новых токенов, услуг или миграции БД.

## Поведение

- HTTP 507, временные HTTP 5xx/408/429 и сетевые ошибки Railway вызывают
  общую паузу минимум на 60 секунд. Это не считается недоступностью оригинала ЕИС.
- Неотправленный результат задания остаётся в памяти вкладки и отправляется
  повторно **до** получения следующего задания. Успешный результат не заменяется
  частичным из-за сбоя доставки отчёта.
- Отложенное задание возвращает одну попытку активной аренды. Повторная доставка
  того же отчёта не возвращает её второй раз. Реальные ошибки получения оригиналов
  по-прежнему имеют ограниченное число попыток.
- Ошибки сохранения цены/заказчика передаются наверх: сбой Railway не превращает
  проверку метаданных в успешную.
- Проверка свободного места охватывает действующие маршруты метаданных v311/v341.
  CORS-preflight проходит даже при заполнении диска; сам запрос получает 507,
  код `EIS223_STORAGE_FULL` и `Retry-After: 60`.
- После восстановления места обработка разрешена сразу, без перезапуска сервера.

Оригиналы, находки, SQLite и отчёты не удаляются. Правила правового анализа и
подсчёт нарушений не меняются. Секреты в браузерное хранилище не записываются.

## Ограничения

Повторная отправка хранится в памяти работающей вкладки. Закрытие вкладки или
перезапуск браузера её уничтожает; в таком случае действует существующая серверная
аренда задания. Установленный VPS-загрузчик и реальная доставка новых оригиналов
на production этим тестированием не проверялись. Новый код должен быть отдельно
развёрнут; работающую вкладку затем нужно перезапустить с новым collector.js.

## Проверки

- 8 тестов storage guard и 6 тестов очереди: пройдены.
- Node recovery suite: сетевые/HTTP сбои, JSON null/примитивы, восстановление,
  точная повторная доставка, пауза ЕИС, ошибки метаданных: пройдены.
- Старые DOM-наборы v314 и v341 (8 и 30 случаев): пройдены.
- Компиляция Python и JavaScript, `git diff --check`: пройдены.
- Полный unittest: 172 теста, 155 пройдены, 10 failures и 7 errors.
  Те же 17 проблем воспроизводятся на неизменённом `f69a2cc` (158 тестов).
  Это не полный зелёный прогон; проблемы затрагивают старые ожидания кабинета,
  тестовые схемы/фикстуры и проверки изоляции/маршрутов и требуют отдельного разбора.
- 37 из 39 существующих `*_selftest.py` пройдены. `v310_archive_selftest.py`
  заблокирован отсутствием `bsdtar` в локальном окружении;
  `v330_changes_selftest.py` имеет ту же ошибку assertion на baseline.
- Старый `test_v335_price_dom.cjs` обращается к уже отсутствующей функции
  `priceFromDocument`; эта ошибка также воспроизводится на baseline.

CI `collector-recovery.yml` запускает новые целевые тесты и актуальные DOM-регрессии.
Полная сборка Docker и проверка работающего сайта требуют отдельного этапа.
