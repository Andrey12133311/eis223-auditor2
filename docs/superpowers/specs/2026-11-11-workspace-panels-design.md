# Боковые панели и быстрый просмотр закупки

Пользователь попросил попробовать все предложенные улучшения и показать результат после обсуждения левой навигации и правой панели просмотра. Это расширение ранее выбранной светлой компактной темы; опубликованные маршруты и правовая логика сохраняются.

## Поведение

- На общей странице слева постоянное меню220px, сворачиваемое до68px; запоминается только настройка ширины. Пункты ссылаются на существующие страницы. Руководитель/администратор видят только соответствующие их роли ссылки. В существующие рабочие места с собственными меню вторая панель не добавляется.
- На узком экране меню открывается поверх страницы, имеет кнопку закрытия, фон недоступен для фокуса, Tab остаётся внутри меню, Esc возвращает фокус.
- Обычное нажатие на ссылку или строку закупки открывает справа панель до460px. Ctrl/Command/Shift и обычные ссылки без JavaScript сохраняют стандартную навигацию.
- Панель получает HTML существующей сохранённой карточки через GET с текущей сессией. Никакой проверки заново не запускается и новые API не добавляются.
- Вкладки: сводка, замечания, документы. Сводка содержит реальные значения и раздельное состояние документов/юридической проверки. Полные реквизиты раскрываются, доказательства и важные оговорки сохраняются. Полная карточка доступна отдельной ссылкой.
- Ответы отменяются и проверяются по порядковому номеру запроса; старый ответ не может заменить новую закупку. Ошибки и завершение сессии очищают прежнее содержимое и дают понятное действие.
- На телефоне карточка занимает весь экран; фокус ограничен панелью, при закрытии возвращается к исходной ссылке. Фильтры и положение таблицы не меняются.
- HTML правой панели проходит структурную очистку: без scripts/styles/forms/buttons/event-атрибутов/чужихID, ссылки только http(s) без credentials. Читаются только текущий origin и корректные номера закупок.

## Дополнительные улучшения

Краткая сводка карточки и русское отображение сохранённых дат; список документов на телефоне; менее вложенное оформление рабочего места; монохромные SVG; показатели руководителя как доступные кнопки перехода к настоящим фильтрам; явные пустые состояния и сброс фильтра. Просрочка берётся из серверногоoverdue, а не вычисляется в браузере.

В реестре закрепляется существующая панель фильтров, добавляется копирование идентификаторов и выравнивание сумм. Быстрые фильтры создаются только из реально имеющихся вариантов существующегоselect и запускают его существующую кнопку применения. Если подходящих контролов нет, новые состояния не выдумываются.

## Предпросмотр и границы

Используются реальные HTML/JS builders с вымышленными данными. HTML реестра — структурный макет приватного восстанавливаемого runtime. Полный интерактивный макет упаковывается в один HTML; его адаптер локально моделирует запросы, не обращается к продуктивному сайту. Выпуск на рабочем Railway остаётся отдельным действием: пользователь сейчас просил попробовать и показать, а источник Railway ранее менялся параллельно.
