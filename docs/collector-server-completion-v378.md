# V378: завершение загрузки для уже работающих вкладок ЕИС

Дополнение к V377 (`e0b72a5`), без изменения оригиналов, найденных нарушений,
правовых правил, настроек хранилища и подключения источников.

Старая работающая вкладка V376 может отправлять `partial`, когда все оригиналы
сохранены, но серверный анализ ещё идёт. Сервер теперь завершает такое задание
загрузки после собственной проверки манифеста и квитанций сохранённых файлов.
Сообщение сообщает о передаче на проверку, а не о завершённом правовом анализе.

Условия: официальный браузерный манифест этой закупки; все объявленные
вложения имеют отдельные допустимые UID; каждый учтённый оригинал сохранён.
Исторические SOAP-вложения и повтор одного UID не заменяют отсутствующий файл.
Отчёт вкладки и заявленное ею число скачиваний не являются подтверждением.
Проверка файлов происходит до захвата блокировки SQLite. После захвата
повторно читается задание, чтобы сохранить завершённый параллельным процессом
результат. Задания по ИНН, метаданным и инфраструктурные отсрочки не меняются.

Проверки: 13 серверных регрессий с реальными манифестами, файлами и квитанциями;
6 проверок API карточек через действующий шлюз авторизации и CORS; существующие
тесты восстановления очереди V376, метаданных V377 и самопроверки тематической
диспетчеризации и самостоятельного кабинета. Проверки выполняются без доступа
к реальным документам и без изменения production-данных.

Изменение применяется к следующим отчётам уже работающих вкладок после
развёртывания сервера. Само по себе оно не создаёт подключение VPS к ЕИС.
