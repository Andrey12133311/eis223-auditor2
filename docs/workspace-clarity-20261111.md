# Понятный рабочий интерфейс: отдельные представления

Следующий этап уточняет форму запуска и остальные страницы: [ui-workflows-20261111.md](ui-workflows-20261111.md). В итоговой версии поле номера и настоящая кнопка отправки находятся рядом в заголовке кабинета; приведённое ниже описание focus-only CTA относится к предыдущему этапу.

## Что изменено и зачем

Предыдущий макет раскрывал личный кабинет над реестром. При этом переходы повторялись в шапке, меню и ярлыках, а выбранный пункт меню продолжал указывать на реестр. Пользователь видел несколько похожих рабочих областей одновременно.

Теперь «Мой кабинет» и «Реестр закупок» показываются раздельно. В меню выбран ровно один раздел; его состояние соответствует содержимому. Ссылка /#cabinet открывает кабинет напрямую. Back/Forward восстанавливают подходящее представление; фильтры и прокрутка реестра сохраняются. После возврата в длинный список фокус остаётся на видимом элементе, а не на заголовке выше экрана.

Кабинет получил ясный заголовок, пояснение и одно основное действие «Проверить закупку». Оно только фокусирует существующее поле номера ЕИС, не отправляя запрос на проверку автоматически. Основной список шире, состояния документов и юридической проверки разделены, действия сгруппированы. Неизвестные числовые значения показываются как «—», а не как ноль. Повторяющиеся переходы скрываются только при работающей новой оболочке; прежний fallback, маршруты, ролевые инструменты и все DOM ID сохраняются.

Счётчики стали спокойной строкой сведений, вторичные раскрывающиеся блоки — единым списком. Мобильная шапка упорядочена в два ряда. Доступ к профилю находится в блоке пользователя. «Рабочее место» переименовано в «Задачи и поручения», обзор рабочего места — в «Сводка»; серверные маршруты и идентификаторы вкладок не менялись.

## Проверка

- 99 unittest-проверок: OK, один существующий skip.
- v362_ui_auth_selftest и v364_eis_design_selftest: OK.
- 239 браузерных сценариев: без ошибок и исключений JavaScript. Включены разделение представлений, активное меню, прямой hash-вход, Back/Forward, отсутствие автоматической отправки CTA, сохранение фильтров и прокрутки, инспектор из кабинета, старые защиты от гонок и недоверенного HTML, а также видимость фокуса после возврата к длинному списку на компьютере/телефоне.
- 18 проверок автономного HTML: без сетевых запросов и ошибок JavaScript.
- Независимое ревью выявило перенос фокуса на невидимый заголовок; исправление подтверждено шестью браузерными регрессиями на длинном реестре.

Проверки используют реальные builders и согласованные вымышленные данные. HTML реестра остаётся структурным макетом закрытого восстанавливаемого runtime. Полная продуктивная авторизованная сессия не использовалась. Известные baseline-таймауты расширенных ASGI-наборов описаны в предыдущих отчётах и не выдаются за пройденные проверки.

## Предпросмотр

```sh
PYTHONPATH=.:scripts python tools/render_interface_preview.py --output /tmp/eis-clarity-preview
PYTHONPATH=.:scripts python tools/export_interface_demo.py --output /tmp/eis-clarity-preview/preview.html
```

Автономный HTML содержит отдельный пункт выбора «Мой кабинет» и моделирует данные только внутри артефакта. Адаптер не добавляется в продуктивное приложение.

Этап изменяет только представление и локальные UI-контролы. Авторизация, владение данными, решения правового аудита, экспорт, БД, настройки и развёртывание Railway не менялись. Изменения направляются в ранее разрешённый draft PR113; публикация сайта остаётся отдельным действием.

## Объединённое меню

По следующему пожеланию пользователя группы «Рабочая область» и «Моя работа» объединены в один раздел «Основное». Все семь пунктов, маршруты и активные состояния сохранены. Ролевое «Управление» остаётся отдельным, профиль закреплён внизу; на коротком экране меню прокручивается целиком. Подпись «Тематические проверки» раскрыта полностью.

Действие личного списка уточнено до «Убрать из списка» и оформлено спокойно: существующее подтверждение и API удаления только из личного списка не менялись, оригиналы/результаты не удаляются.

Свежая проверка этого небольшого изменения: 16 целевых unit-тестов, 32 проверки навигации в Chromium; дополнительно проверены размер/контраст и размещение уточнённого действия на 390×600. Ошибок JavaScript и переполнения не обнаружено. Снимки и автономный HTML обновлены; полный предыдущий набор 239 сценариев из-за изменения подписей/группировки повторно не запускался.
